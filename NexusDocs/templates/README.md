# Шаблоны запросов NexusDocs

Каталог `requests` содержит полный комплект из 15 независимых DOCX-шаблонов.
Шаблоны 03, 04, 05, 06, 07, 08, 12, 13 и 15 используют
`{{RECIPIENT_HEADER}}`, который определяется по адресу регистрации. Остальные
шесть шаблонов сохраняют фиксированную или предметную шапку исходного документа.

Во время генерации заполняются данные человека, дела, военной службы, паспорта,
исходящего документа и падежные формы ФИО. Перед выпуском комплекта пользователь
может вручную исправить автоматически рассчитанные склонения.

Старое подключение Word Mail Merge к Excel удалено. В шаблонах нет внешних
источников данных и полей `MERGEFIELD`.
