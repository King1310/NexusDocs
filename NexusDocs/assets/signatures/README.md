# Подпись для комплекта запросов

Подпись выбирается по исполнителю, сохранённому у человека:

- `tsomartov_sa.png` — С. А. Цомартов;
- `litvinov_vn.png` — В. Н. Литвинов;
- `sarkisyan_ak.png` — А. К. Саркисян.

Это изображения из предоставленных сканов. Они вставляются в подписные строки
запросов, включая формы МВД без строки звания. Упоминания фамилии в контактных
сведениях не являются местом для подписи.

Существующая подпись О. Р. Агирова из шаблона ВСУ по РВСН сохраняется в общем
комплекте. Исходный шаблон не изменяется.

PNG не включаются в Git. На рабочих компьютерах они должны устанавливаться
отдельно в защищённое локальное хранилище либо предоставляться внутренним
сервером. Исходные PDF не изменяются.

Важно: подпись невозможно надёжно скрыть от пользователя, который получает
подписанный DOCX — документ является ZIP-контейнером с вложенными изображениями.
Для централизованной версии безопаснее формировать подписанные документы на
внутреннем сервере и не включать исходные PNG в клиентский EXE.

Word с подписью остаётся редактируемым. Перед отдельной подготовкой PDF нужно
проверить документ и сохранить правки. Встроенная картинка не является
криптографической электронной подписью.
